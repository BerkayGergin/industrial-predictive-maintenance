Structured node tree, stable string NodeIds, subscription-based acquisition and writable simulator controls.

Historian

Every analyzed snapshot is stored in a TimescaleDB hypertable so current state and history are separate concerns.

Explainable Analytics

Anomaly score uses load-compensated residuals against a frozen healthy baseline. Health score combines measurable penalties.

Alarm Lifecycle

Alarms persist independently of the browser and keep activation, acknowledgement, escalation and clear timestamps.

This is a learning/prototyping platform, not a certified machinery protection or production RUL forecasting system.
